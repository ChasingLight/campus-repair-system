# 通用强制约束

本文档汇总本 Skill 中所有强制约束，供快速查阅。集成代码前必须完整阅读并理解。

---

## 私钥强制规则

| 编号 | 约束项 | 规则说明 |
|------|--------|----------|
| C-01 | **私钥来源** | 必须使用沙箱返回的 `appPrivatePkcsKey` 字段，禁止自行生成、格式转换或使用其他来源的私钥 |
| C-02 | **沙箱返回格式** | 沙箱同时返回 `appPrivateKey`（PKCS#8）和 `appPrivatePkcsKey`（PKCS#1），必须使用 `appPrivatePkcsKey` |
| C-03 | **PEM 头尾禁止** | 禁止手动添加 PEM 头尾（如 `-----BEGIN RSA PRIVATE KEY-----`），SDK 内部自动处理格式 |
| C-04 | **禁止假数据** | 不得自行生成示例私钥、示例账号等，所有配置必须来自沙箱实际返回或用户自行提供 |

## 沙箱环境绝对禁止事项

> 违反以下任何一条，立即停止所有后续步骤，不得输出代码、配置文件或任何集成建议

| 编号 | 禁止项 | 规则说明 |
|------|--------|----------|
| S-01 | **禁止编造配置** | 不得生成、拼接、模拟、猜测 appId、私钥、公钥、账号等任何字段值 |
| S-02 | **禁止占位符冒充** | 沙箱成功返回完整配置时，禁止用占位符（如 `your-app-id-here`、`xxx`）代替真实返回值 |
| S-03 | **禁止假数据** | 不得自行生成示例私钥、示例账号等 |
| S-04 | **禁止部分通过** | 任一字段缺失即表明快速沙箱环境创建失败，必须进行重试 |
| S-05 | **重试失败处理** | 反复重试失败则提示用户自行申领沙箱或重新输入创建快速沙箱指令 |

## SDK 集成致命错误

> 违反以下任何一条将直接导致集成失败

| 编号 | 约束项 | 规则说明 |
|------|--------|----------|
| SDK-01 | **私钥字段选择** | 必须使用沙箱返回的 `appPrivatePkcsKey` 字段 |
| SDK-02 | **导入方式** | SDK 导入方式取决于包的实际导出方式，**必须**通过查看 `.d.ts` 文件确定是命名导出还是默认导出 |
| SDK-03 | **页面跳转 API** | `alipay.trade.page.pay` / `alipay.trade.wap.pay` 必须使用 `pageExecute()` 或 `pageExec()`，使用 `exec()` 将无法获取支付表单 |
| SDK-04 | **时间戳格式** | 必须使用 `yyyy-MM-dd HH:mm:ss`，禁止使用 ISO 格式 |
| SDK-05 | **前端跳转方式** | `pageExecute()` 返回的是 HTML 表单字符串，前端必须渲染该 HTML 并自动提交 form，使用 `window.location.href` 会导致页面只显示 URL 参数 |
| SDK-06 | **验签失败排查原则** | 遇到 `invalid-signature` 报错时，**严禁凭猜测归因到私钥格式**。最常见原因是请求参数不完整（如 `return_url` 未传入） |

## 代码生成前自检清单

> 输出任何代码之前，必须逐条自检以下 8 项，全部通过方可输出代码

| 编号 | 检查项 | 判定标准 |
|------|--------|----------|
| CHECK-01 | 私钥来源 | 我使用的私钥是沙箱返回的 `appPrivatePkcsKey` 字段吗？ |
| CHECK-02 | SDK 导入方式 | 我确定的 SDK 导入方式是通过查看 `.d.ts` 文件得出的吗？ |
| CHECK-03 | API 调用方式 | 我用的是 `pageExecute()`/`pageExec()` 而非 `exec()` 吗？ |
| CHECK-04 | 时间戳格式 | 时间戳格式是 `yyyy-MM-dd HH:mm:ss` 吗？ |
| CHECK-05 | 前端渲染方式 | 前端是否将 `pageExecute()` 返回的 HTML 表单渲染并自动提交？ |
| CHECK-06 | 数据真实性 | 沙箱配置中没有任何编造、假数据，且占位符仅用于用户选择自行申领的场景吗？ |
| CHECK-07 | 配置存储位置 | 沙箱环境信息（appId、appPrivatePkcsKey、alipayPublicKey 等）仅存放在 `alipay-sdk-config` 文件中，没有写入其他任何文件吗？ |
| CHECK-08 | 沙箱域名检测 | 我是否已在 `build.sh` 中添加沙箱域名检测逻辑（检测 `alipaydev.com`）？ |

## 配置存储约束

> 代码输出完成后必须主动验证，违反以下任何一条必须当场修正

| 编号 | 约束项 | 规则说明 |
|------|--------|----------|
| CONFIG-01 | **配置集中存储** | 沙箱环境信息（appId、appPrivatePkcsKey、alipayPublicKey 等）**禁止**存放在除 `alipay-sdk-config` 以外的任何配置文件中 |
| CONFIG-02 | **构建时沙箱检测** | 构建脚本 `build.sh` 必须检测 `alipay-sdk-config` 文件，若检测到沙箱域名 `alipaydev.com`，则构建失败并报错。代码输出后必须验证 `build.sh` 中包含检测逻辑 |
