# Flow Skeleton

服务市场上架流程骨架，执行基座为 `alipay-cli`，所有机读结果统一按 `--json` 解析。

**⚠️ 重要：此流程仅对"智能收"产品需要（salesCode = I1080300001000160457）**

## 主流程骨架

1. **判断产品类型**（前置条件）
2. 从共享内存读取已采集的服务信息（主技能 Step 5 已采集）
3. 提交服务上架
4. 更新共享内存状态

**⚠️ 注意：登录态检查和 MCP 可用性检查由主 skill 负责，本子技能不单独处理。**

## 前置判断: 产品类型检查

**在进入服务市场上架流程前，必须先判断产品类型：**

```bash
STATE_MANAGER=<skill-dir>/scripts/state_manager.py
SALES_CODE=$(python3 "$STATE_MANAGER" get salesCode)

# 判断是否为智能收产品
if [ "$SALES_CODE" != "I1080300001000160457" ]; then
  echo "ℹ️ 当前产品（$SALES_CODE）无需服务市场上架，跳过此流程"
  exit 0
fi

echo "✅ 智能收产品，需要服务市场上架"
# 继续后续流程...
```

**产品类型与是否需要服务市场上架：**

| 产品 | salesCode | 需要服务市场上架 |
|------|-----------|------------------|
| 智能收 | I1080300001000160457 | ✅ 是 |
| 电脑网站支付 | I1080300001000041203 | ❌ 否 |

## 总体原则

- 意图不明确时先问，不自动调 tool
- tool 报错时直接把错误返回给用户，由用户决定下一步
- 服务信息由主技能 Step 5 采集并写入共享内存，本流程从共享内存读取
- 用户确认后再提交上架
- **登录态检查和 MCP 可用性检查由主 skill 负责**

### 数据验证

每项收集后立即验证：

| 字段 | 验证规则 |
|------|----------|
| `serviceName` | 长度 1-50 字符 |
| `serviceDesc` | 长度 1-500 字符 |
| `resourceUrl` | 以 http/https 开头 |
| `pricing` | 数字且 >= 0.01 |
| `schemaUrl` | 有效的 JSON 格式 |

### 用户响应处理

| 响应 | 处理 |
|------|------|
| 确认 | 进入提交阶段 |
| 修改 | 允许用户修改指定项，更新共享内存后重新确认 |
| 取消 | 结束流程 |

## 阶段 3: 提交上架

用户确认后，执行 `saveBazaarServiceForMcp` 提交上架。

```bash
SUBMIT_RESULT=$(alipay-cli mcp call a2a-pay-service.saveBazaarServiceForMcp \
  -d '{"request":{"serviceName":"'"$SERVICE_NAME"'","serviceDesc":"'"$SERVICE_DESC"'","resourceUrl":"'"$RESOURCE_URL"'","pricing":"'"$PRICING"'","schemaUrl":"'"$SCHEMA_URL"'"}}' \
  --json 2>/dev/null)
```

### 提交结果处理

| 结果 | 处理 |
|------|------|
| 成功 | 展示成功信息，更新状态文件 |
| 失败 | 展示错误信息，提示用户重试或修改 |

### 成功输出格式

```
✅ 服务上架成功！

📋 服务信息：
   服务ID：xxx
   服务名称：天气查询
   状态：审核中

💡 服务上架后需要经过审核，审核通过后即可在服务市场上架。
   您可以在支付宝开放平台查看审核进度。
```

服务市场上架成功后，注册结果作为运行时变量返回，不写入共享内存状态文件：

```bash
# ⚠️ 禁止写入 service_market_data 到状态文件（不在允许的 4 个字段内）
# 注册结果（serviceId, status 等）作为运行时变量返回给主技能
```

## 阶段恢复提示

| 阶段 | 恢复动作 |
|------|----------|
| 信息读取 | 从共享内存读取已采集的数据，如不完整则报错 |
| 用户确认 | 重新展示信息，等待确认 |
| 提交上架 | 检查共享内存，如已提交则提示用户去开放平台查看 |

## 错误处理

详见 `references/error-handling.md`（若存在）或主技能的 `references/error-handling.md`。

### 常见错误

| 错误类型 | 处理方式 |
|----------|----------|
| 认证错误 | 提示重新登录 |
| 网络错误 | 提示稍后重试 |
| 参数验证失败 | 提示用户修改对应字段 |
| 服务名称已存在 | 提示用户更换服务名称 |

## 说明

- 主流程默认强推进
- 只在错误、用户决策节点停住
- 数据由主技能 Step 5 采集，本流程从共享内存读取
