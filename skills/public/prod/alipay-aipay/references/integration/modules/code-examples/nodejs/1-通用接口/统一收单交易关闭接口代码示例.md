# 统一收单交易关闭接口 - Node.js 示例

## 请求示例

```javascript
// alipaySdk 必须由项目中当前已验证的生效配置工厂提供，禁止在源码中粘贴凭证。
async function closeUnpaidTrade(alipaySdk, outTradeNo) {
  const result = await alipaySdk.exec("alipay.trade.close", {
    bizContent: {
      out_trade_no: outTradeNo,
    },
  });

  if (result.code !== "10000") {
    throw new Error("alipay.trade.close failed");
  }
  return result;
}
```

## 响应示例
### 正常示例
```json
{
    "code": "10000",
    "msg": "Success",
    "trade_no": "ALIPAY_TRADE_NO_PLACEHOLDER",
    "out_trade_no": "MERCHANT_ORDER_NO_PLACEHOLDER"
}
```
### 异常示例
```json
{
    "code": "20000",
    "msg": "Service Currently Unavailable",
    "sub_code": "isp.unknow-error",
    "sub_msg": "系统繁忙"
}
```
