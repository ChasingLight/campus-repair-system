# 统一收单交易退款查询接口 - Node.js 示例

## 请求示例

```javascript
// alipaySdk 必须由项目中当前已验证的生效配置工厂提供，禁止在源码中粘贴凭证。
async function queryRefund(alipaySdk, outTradeNo, outRequestNo) {
  const result = await alipaySdk.exec("alipay.trade.fastpay.refund.query", {
    bizContent: {
      out_trade_no: outTradeNo,
      out_request_no: outRequestNo,
    },
  });

  if (result.code !== "10000") {
    throw new Error("alipay.trade.fastpay.refund.query failed");
  }
  return {
    result,
    refunded: result.refund_status === "REFUND_SUCCESS",
  };
}
```
